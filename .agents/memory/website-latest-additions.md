**Why:** المستخدم اختار التحميل التدريجي لتجنب عرض قائمة كبيرة مرة واحدة، وأراد الزر كي يبقى التحميل اليدوي متاحاً وواضحاً.

**How to apply:** أبقِ ترتيب الأحدث، وتجنب تكرار العناصر بين الدفعات، وأخفِ الزر بعد تحميل كل العناصر. حدّث نتائج القائمة عند إضافة ملفات أو تغيير ظهورها بالموقع.
