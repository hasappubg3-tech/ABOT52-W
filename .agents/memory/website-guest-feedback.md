---
name: Website guest feedback policy
description: Anonymous participation chosen by the user, and synchronization tradeoffs with Telegram.
---

The user chose guest participation: «لا يشترط اي شخص يكدر يعلق او يقيم لكن للتعليق عليه كتابه اسم».

**Why:** The user explicitly does not require Telegram login; a name is required only for comments, not ratings.

**How to apply:** Keep website participation available without account authentication. Names are self-declared, not verified Telegram identities. Website guest ownership is separate from Telegram-account ownership; do not represent a guest as the same authenticated person in the bot.

Independent file pages must still respect the bot's existing shared-rating configuration. When Telegram groups feedback for a content button, those website files share its feedback; separating their page presentation must not create incompatible feedback records.

**Why:** The requested two-way synchronization has to work without editing the bot, whose feedback can be unified across files and linked menus.

**How to apply:** Explain shared feedback on affected file pages. Do not split those ratings into independent website-only records unless the user changes the synchronization requirement.
