عناوين ملفات الأجوبة النموذجية في الموقع تكون: «الجواب النموذجي لأسئلة مادة {المادة} {السنة} {الدور} {التفاصيل المتوفرة} للصف السادس العلمي».

**Why:** المستخدم رفض العنوان العام «الأجوبة النموذجية الصف السادس العلمي» وطلب إظهار المادة والسنة والدور والفرع.

**How to apply:** وحّد العنوان بين بطاقة الملف وصفحته والبحث وآخر الإضافات والملفات المشابهة وبيانات الصفحة، مع بقاء ملفات كل زر مستقلة وعدم تعديل بيانات البوت.

احتفظ بكل التفاصيل المتوفرة، بما فيها أحيائي وتطبيقي وأدبي وعلمي ونازحين وخارج القطر وتكميلي ومحاولات. إذا لم تتوفر معلومة، فاتركها غير مذكورة؛ لا تخمّن ولا تكتب «غير محدد».

**Why:** المستخدم اختار صراحةً إظهار كل التفاصيل وحذف الأجزاء الناقصة دون تخمين.

**How to apply:** مسار الملف في البوت يحدد المادة والسنة والدور عندما تكون موجودة؛ استخدم وصف الملف واسمه لسد النواقص فقط، ولا تستنتج الفرع من اسم الصف أو بيانات ملف مجاور.

احتُفظ بروابط الملفات الحالية عند تغيير عناوين عرض الأجوبة.

**Why:** الطلب يخص العناوين، وليس تغيير الروابط المفهرسة أو كسر الروابط المتداولة.

**How to apply:** لا تجعل تغيير تنسيق العنوان يغيّر الروابط القديمة تلقائياً؛ أي إعادة تسمية مستقبلية للروابط تحتاج إعادة توجيه آمنة.
