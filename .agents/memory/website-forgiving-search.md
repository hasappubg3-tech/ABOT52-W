---
name: Forgiving website search
description: Product intent for natural Arabic student searches and relevance.
---

The user wants website search to be «مفتوح جدا مثل البحث باليوتيوب وباقي المواقع بحيث سهل جدا تحصل نتيجة وان كان الكتابة غير واضحة».

**Why:** Students writing «ملزمه» instead of «ملزمة», or adding words around «حسين الهاشمي», were getting no results. Strict all-word matching is not the intended experience.

**How to apply:** Preserve tolerance for common Arabic spelling variants, small spelling errors, and extra conversational words. Rank matching teachers/subjects ahead of incidental word matches, rather than treating broad matching as permission to return unrelated materials. Each PDF remains independent; another file's teacher/caption must not become its searchable identity.
