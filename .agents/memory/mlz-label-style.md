---
name: Automatic material-title style
description: User-required ordering and emoji selection for automatic material additions.
---

Automatic material names must use: material type + year + the user's selected custom emoji, once at the end. Do not wrap titles in pushpin emojis.

**Why:** The user requested this format and asked to correct existing material titles generated with a pushpin on each side.

**How to apply:** Keep type detection separate from formatting. Reuse the selected custom emoji rather than guessing a decorative symbol. When repairing titles, preserve button identities, file records, links, feedback, and menu mirroring; restrict changes to malformed material names.
